## 数据与安全

- 全部栏目数据保存在**本机浏览器**（IndexedDB / localStorage），服务器零存储。
- **敏感资料不部署**：国数案例原始文件（docx/pptx）未上传（公开站点不得放内部资料）。手机端使用数智学习时：
  - 已云同步过的来源解析文本会通过「设置中心 → 云同步」从你的 GitHub 私有仓库自动拉到手机；
  - 超大来源（单来源解析文本 >200KB）仅同步登记信息，如需全文请在手机端重新导入文件。
- 云同步 = 学习记录（含案例解析文本）外发至你本人 GitHub **私有**仓库，请确认后再启用。
