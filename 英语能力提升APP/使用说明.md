# AI英语教练 · 使用说明

个人 AI 英语私人教练（千手学习Agent 第4栏目）。目标不是背单词，而是 90 天把英语变成获取全球 AI/科技信息的工作工具。

## 一、怎么打开

1. 双击项目根 `启动.vbs` → 浏览器打开千手统一首页。
2. 点第4张栏目卡片「**AI英语教练**」进入。
3. 顶部固定返回栏随时回首页；数据与其他栏目完全隔离（独立 IndexedDB `coach_agent_db` + `coach_` 前缀）。

## 二、第一次使用（10–15 分钟）

1. **先配 AI**（必须）：千手首页右上角「设置中心 → AI 服务」填 OpenAI 兼容地址与密钥（MiniMax 填 `https://api.minimax.cn`，模型 `MiniMax-M2.5` 或 `MiniMax-M3.1-Flash-Preview`），点"测试连接"。保存即可，本栏目直接共用（统一登录统一设置）。
2. （可选）同页开启「**允许云端语音判断**」——语音识别需要把录音发给 MiniMax，不开则语音功能不可用（文字输入照常）。
3. 进入栏目 → 「开始测评」：简单阅读 → 听力 → 词汇 → 口语 → 写作，五段约 10–15 分钟 → 生成你的 9 维能力画像。
   - 说不出、听不懂都没关系，这正是教练要补的；也可以先「跳过」用保守默认值，学习过程中会持续隐式重估。
4. **练听力想用真人感语音**：设置中心「AI 语音合成」配 MiniMax T2A（与数智学习共用同一份配置）。

## 三、每天怎么学（不用思考）

打开就是 **Today's Mission**：AI 根据你的可用时间、到期复习、最近错误、当前阶段自动排好今天的块（复习→阅读→听力→对话→写作），点 **Start Learning** 逐块执行即可。

- **碎片时间**：每块 5–15 分钟；中途点"先到这里"退出，下次打开 Continue 从断点继续。
- **今日没空**：开 Quick 5——复习队列自动出 5 分钟内容。
- **周末**：60 分钟版计划自动生成（Deep Study 深度学一篇真实文章）。

## 四、真实英文内容从哪来

三条通道，见「阅读」页：

1. **内置种子**：首次自动加载 3 篇原创 AI 主题短文（What is an AI Agent? 等），Day1 就能学。
2. **采集脚本**（推荐，真实世界内容）：本地运行 `docs/curator.py`
   ```
   python docs/curator.py --limit 5
   python docs/curator.py --proxy 127.0.0.1:12334   # 海外源走 Harbor 代理
   python docs/curator.py --url https://某篇文章
   ```
   输出 `content-pack.json` → 在「阅读」页「导入内容包 JSON」→ 点「**AI 加工**」（生成简化版/词汇分类/讨论问题/听力脚本）→ 阅读。
   版权原则：只存标题/链接/来源/摘录（前1200字符），学习材料由 AI 基于摘录生成，不复制全文。
3. **手动粘贴**：任何英文文章粘贴导入。

**阅读体验**：三级切换（Level 1 简化版 / Level 2 要点 / Level 3 原文节选+打开原文链接）；点文中生词即查——AI 按 A（高频工作词，建议学习）/ B（一般）/ C（低频，不打断）分类，A 类一键入库进复习队列。

## 五、口语对话（重点功能）

「对话」页选情境开麦即说（或任务里自动安排）：

- 情境围绕你的工作：认识美国 AI 从业者、介绍你的工作、介绍 AI 产品、讨论 Agent、解释数字化项目、海外客户闲聊。
- **分层纠错，不打断**：小问题不纠；表达不自然时教练先提示"Something sounds a little unusual… Which word usually comes before 'like'?"——让你自己想；想不出再给自然表达，你跟读一遍。错误自动结构化入库，进入复习。
- 每轮不评分，结束给"**今天最值得改进的一件事**"，最多 1–2 个重点。
- **诚实边界**：发音只有"ASR 可懂度"参考（识别对了≈人能听懂），绝不做无依据的音素评分；AI 未配置时对话照常保存但不伪造评估。

**语音说明（重要）**：语音识别主通道为 MiniMax ASR（上传音频文件模式），浏览器原生识别作回退，可在「设置」页切换。首次用语音请到「设置」页点「测试识别」真实验证；若报错，把"端点路径"改成官方文档路径即可。**本地 file:// 双击打开时，浏览器可能限制麦克风**——此时用文字输入回退，或部署到 GitHub Pages（https）后语音全功能可用。

## 六、复习与掌握（不是背单词）

- 复习对象 7 类：词汇/表达/我的错误/听力难点/发音难点/句型——复习形式按对象不同（词过证据阶梯、错误换新场景重测、听力重听复述）。
- 间隔 0/1/2/3/7/14 天可解释调度：说没想起来→明天再见；独立正确→进入下个间隔。每项带"为什么是这一天"的规则说明。
- **认识 ≠ 掌握**：0–5 证据阶梯（看过→看懂→听懂→能用→对话中自然使用），只有真实使用证据才升级，选择题猜中不算。
- 掌握测试不问"记住了吗"，而是给新场景让你自然使用——用对升级，不会降级。

## 七、数据、备份与多端同步

- 全部学习数据存本机浏览器 IndexedDB；密钥只存 localStorage，不进源码/仓库。
- **多端自动同步**：与英语栏目同机制——学习数据变化后约 25 秒自动上传 GitHub 私有仓库（coach-data.json，本栏目独立文件），打开应用自动拉取云端新数据，每 5 分钟兑底补推；覆盖前自动留档，不丢数据。**零额外配置**：千手首页「设置中心 → 云同步」配好仓库/令牌后自动生效（两栏目共用同一仓库、各自独立文件）。也可在「设置」页手动"立即同步/仅拉取"。
- **导出/导入兑底**：「设置」页可导出全部 19 张表 JSON 备份，另一台设备导入恢复。
- 「删除本栏目全部数据」有二次确认，不影响其他栏目。

## 八、常见问题

| 症状 | 处理 |
|---|---|
| 点 AI 功能报"AI 未配置" | 千手首页 → 设置中心 → AI 服务，填地址/模型/密钥并保存 |
| 计划/内容标"规则模板" | AI 未配置或调用失败的诚实兜底，配置好 AI 后点"重新生成今日计划" |
| 语音识别失败 | 设置页点「测试识别」看真实报错：密钥不对→查设置；"音频上传未授权"→设置中心开启云端语音判断；file:// 限麦→改用文字输入或上 GitHub Pages |
| AI 加工很慢 | 推理型模型正常现象（1–3 分钟），顶部状态条消失即完成 |
| RSS 部分源失败 | 海外源需代理：`--proxy 127.0.0.1:12334`；失效源脚本会如实跳过 |
| 手机上用 | 整个目录同步到手机或访问 GitHub Pages，响应式设计直接可用 |

## 九、诚实边界（不吹牛清单）

- 发音只做 ASR 可懂度代理，不做音素级评分（如需专业评分，后续单独评估第三方服务，音频上云前会先征求你同意）。
- AI 未配置/失败时用规则模板兜底并醒目标注，绝不伪造 AI 输出。
- 9 维能力是"训练证据的内部估计"，不是考试分数；不给"英语总分"。
- 静态站点无后台：不做关闭时的系统通知（后续可配 Windows 计划任务）。
- 不承诺 90 天流利；承诺的是让英语逐步成为你的工具。
