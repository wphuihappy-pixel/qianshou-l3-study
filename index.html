同步多端数据同步

通过 GitHub Gist 在电脑与手机之间自动同步学习数据，配置一次后全自动
Personal Access Token，仅保存在本机浏览器，用于读写你的 Gist
尚未同步
配置步骤（一次性，约2分钟）
1. 打开 https://github.com/settings/tokens → Generate new token (classic)
2. 勾选 gist 权限，生成后复制 Token（ghp_ 开头）
3. 将 Token 填入上方输入框，同步方式选「自动同步」，点「保存同步配置」
4. 点「立即上传」把当前数据推到云端
5. 在另一台设备打开本页面，填入同一个 Token，选自动同步，保存后会自动拉取云端数据

配置完成后日常使用无需任何操作：打开页面自动合并最新数据，学习后自动推送。
「上传」= 本地数据覆盖云端；「合并」= 两端数据取并集（推荐）；「覆盖」= 云端覆盖本地（恢复用）。
