AI 语音合成（真人感 TTS）

「数智学习」栏目用它在课程页生成可下载的真实 MP3/WAV（MiniMax 等真人感语音，非 Windows 系统语音）；配置在这里改，栏目里同步生效（共用同一份本机数据）。

未配置

地址带不带 /v1 都会自动识别（MiniMax 填 https://api.minimaxi.com 即可）。测试合成会真实调用一次 TTS 并校验音频文件头（MP3 须 ID3/MPEG 同步头），绝不伪造成功。常见报错：「状态码 1004」= 密钥不对；「Failed to fetch」= 跨域拦截或网络不通；「返回的不是 JSON」= 地址或路径不对。密钥仅存本机浏览器。MiniMax 下 MP3 与 WAV 各合成一次，注意字符额度。

云同步（英语 / 数智 / AI英语教练）

把各栏目学习记录同步到 GitHub 私有仓库，手机和电脑进度互通。英语、数智学习、AI英语教练共用此配置，各写各的数据文件（progress.json / szn-data.json / coach-data.json），互不干扰。

未启用

令牌只存本机。同步冲突时以合并规则处理，不会产生重复学习记录；网络不可用时本地学习不受影响。数智学习与 AI英语教练栏目自动复用此配置（无需在栏目内重复填写）；产数栏目的数据与这些栏目完全隔离（不同命名空间）。

数据备份与隐私

本机数据可随时导出；音频默认不长期保存。

导出文件包含该栏目的全部学习记录与词库，可在另一台设备导入恢复。导入前请确认文件来自可信来源。音频默认不保存；如家长需要留存朗读录音，请在英语栏目设置中明确开启并知晓保存位置。
