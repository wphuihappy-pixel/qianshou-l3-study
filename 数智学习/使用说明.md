# 数智学习 · 使用说明

## 一、怎么开始（5 分钟）

1. 双击桌面「千手学习Agent」图标（或本文件夹上一级的 `启动.vbs`）。
2. 在统一首页点「**数智学习**」卡片进入。
3. 按首页提示三步走：**学习目标 → 资料库导入 → 课程计划**。

## 二、先做这两件事（只做一次）

### 1. 配置真人感 AI 语音（你要的 MP3/WAV 就靠它）

入口在**统一首页右上角「设置中心」→「AI 语音合成（真人感 TTS）」卡片**（和 AI 服务、语音放在一起，一处配置全项目共用；在数智学习栏目内的「音频与数据」页也能看到同一份配置，改哪边都生效）：

| 填什么 | 怎么填 |
|---|---|
| 启用 TTS | 启用 |
| Provider | MiniMax 真人感语音（已设为默认） |
| 接口地址 | `https://api.minimax.cn`（实测推荐，与 DeepTutor 同域）或 `https://api.minimaxi.com`（MiniMax 官方；带不带 /v1 都会自动识别） |
| API 密钥 | 你 MiniMax 平台的 API Key（只存这台电脑，不进任何仓库） |
| 模型 | 留空默认 speech-2.8-hd（推荐）；或选 2.6-hd / *-turbo（更快更省） |
| 音色 | 下拉选常用音色（MiniMax 12 款男/女/主持人/有声书；OpenAI 6 款），或手动输入任意音色 ID；点「试听」用当前音色真实合成一句样张并播放，满意后点「保存 TTS 配置」 |

填完点「**测试合成**」：显示"合成成功 · audio/mpeg · xxKB"就通了。以后每课点「生成本课音频」即可得到**真人感 MP3 + WAV 两种真实音频文件**（不是 Windows 系统语音），可单段下载、也可**合并下载整课音频（MP3）**（把当天所有分段在本地拼成一个 MP3，方便拷到手机/播放器一口气听）或整课打包 ZIP（含脚本/时长/版本清单）。合并是本机计算，不联网；整课较长时页面会短暂卡一下，属正常。2026-10-07 起音频段首不再朗读"第X段/时间段"等标记，整课听感更连贯（**已生成的旧教案需重新生成音频才生效**）。

说明：MiniMax 下 MP3 和 WAV 是各自真实合成一次（同一段文字合成两次，注意你的字符额度）。密钥随时可点「删除密钥」清掉。

### 2. 配置 AI（课程和教案要它才"真"）

回到**统一首页 → 设置中心 → AI 服务**，填你已有的 OpenAI 兼容接口（地址/模型/密钥），点"测试连接"通过即可。MiniMax 实测配置：地址 `https://api.minimax.cn/v1`、模型 `MiniMax-Text-01`（非推理型，直接输出 JSON）或 `abab6.5s-chat`、密钥与 TTS 同一个 Key。
> ⚠️ **不要填 MiniMax-M2.5/M3 等推理型模型**——它们会把思考过程混在 content 里，导致“AI 返回格式异常”。如果必须用推理型模型，应用已做兼容（从输出末尾提取 JSON），但不如非推理型稳定。

- 配了 AI：课程和教案基于《附件1 能力标准》+ 真实案例生成，事实逐条带来源引用。
- 没配 AI：应用会给**演示模板**先跑通流程——所有演示内容都打了醒目红色"演示"标签，不会冒充真实标准，跑通后你随时配 AI 重新生成正式课程。

## 三、日常学习怎么转

1. **导入资料**（资料库页）：把获准的案例 docx/pptx/html 和《附件1 能力标准(1).docx》拖进去。原件永远只读，应用存副本。伪装格式会被拒绝并告诉你原因。HTML 文件（如《总装图.html》）也支持：提取标题、段落、表格、架构图节点文字和**脚本里的说明文字**（有些架构图页面的说明写在 JS 数据里，应用只提取文字、不执行脚本）。2026-10-06 起脚本说明文字也会入检索，**之前导入过的 HTML 请删掉记录重新导入一次**，否则还是旧内容。HTML 样式排版不还原，只取文字内容。
2. **能力树**（能力树页）：点「从《附件1》提取能力树 + 补全知识点（AI）」让 AI 按原文提取能力项和权重。**三条路径全部补全知识点清单**（每个能力项 3-8 个需掌握的概念/术语，参考产数学习模块的 78 个术语库 + AI 公开知识补充），目标路径标"目标路径"标签置顶作为重点。提取后人工核对，也可逐条增删。履历项（项目金额/签约/部署数量/标杆案例数）永远显示"需真实项目证明"——应用只帮你记证据，不会说你已达标。
3. **课程计划**：按你的目标和每日时间生成 30 天草案 → 你确认后锁定 → 点任意天「锁定当天并生成教案」。**生成期间页面顶部会出现持续显示的黑色状态条、按钮同时禁用**（AI 分两段生成 1~15 天、16~30 天，每段约 30 秒到 3 分钟，共需 1~6 分钟），完成或失败后状态条自动消失，不会再出现"点了没反应"。生成后若个别天的案例来源/练习/产物被 AI 漏掉，应用会**按主题自动检索补全**并在该天标"待核实"，toast 会提示补全了几天的哪类字段——锁定前请核对，可改主题。
4. **每天学习**（课程页）：先选「授课风格」再点生成教案 → 读教案（术语有解释、每段标"来源事实/推断/课堂假设"）→ 听音频/下载 MP3/WAV（也可**合并下载整课音频**，一个 MP3 文件反复听） → 做回忆题和变式练习 → 产出当天的工作物。**授课风格（3 种，按场景选，风格只改变讲法、不降低课程深度）**：第一次学新概念选「资深同事口述」（默认，像懂业务也懂技术的同事带你从技术基础讲起，机制、取舍、客户场景怎么问都讲透）；学过之后快速复习选「高密度知识简报」（按"概念—机制—取舍—风险—客户追问"紧凑回顾，结尾自测）；准备客户沟通、需求澄清或方案评审选「实战顾问简报」（从客户需求切入，比较备选方案，示范话术与判断依据，收尾给评审检查项）。也可点"自定义风格"，把网上看到的好的讲课视频字幕/转录稿粘贴进去，AI 会分析其语言风格提炼成可复用风格。音频讲稿按所选风格写成口语化的完整讲课稿，与教案正文覆盖同一组核心知识，适合反复听。
5. **读不懂就点**：每段下面有「这段没懂 / 不确定 / 需练习 / 已掌握」，相当于给每段打一个掌握状态的"标签"——点中的按钮会变成实心并带 ✓，段落标题旁出现对应颜色的标记徽章，教案正文卡片顶部显示本课标记汇总（如"已标记 3/7 段"），重进页面标记还在。点错了再点一次同一按钮即可取消，点其他按钮即是改状态。点"没懂"→ 选原因 → 选你想要的讲法（更简单解释/换类比/流程图/再来个例子）→ 应用生成替代解释，并把这一块安排进复习计划。
6. **在案例上画重点**（资料库 → 阅读/批注）：选中文字 → 高亮/下划线/文字批注，或点「没懂」标签；画笔可以直接在页面画线。批注重开位置不变，可导出带批注副本（浏览器打印即成 PDF）。原件永远不动。
7. **画像你说算**（学习画像页）：你点的"没懂/掌握"是确定状态；反复播放音频之类只是"低置信推断"，不会自动当你没懂，需你确认才影响安排。可改、可关、可删、可导出，可整门课清空。
8. **多设备同步**（音频与数据页 →「云同步」）：**复用千手首页「设置中心 → 云同步」的配置**（GitHub 用户名/仓库/令牌，与英语/AI英语教练共用一份，本栏目无需重复填）。在千手设置中心勾选启用后，学习记录自动打包到你仓库的独立文件 **szn-data.json** 同步。之后**本地有改动 5 秒后自动上传，每 60 秒自动拉取一次云端**，手机/电脑两端学习记录自动合并：同一段记录两端都改过时以修改时间较新者为准；删除会同步到另一端（若那条记录删除后又被改过则保留）。可随时点「立即同步」手动触发；停用请到千手设置中心取消勾选。

## 四、数据安全（关键承诺）

- 所有学习数据只存在这台电脑的浏览器里，不上传任何服务器。
- 只有几处会出网（都要你主动配置才发生）：AI 生成课程/教案（发送能力树+案例片段+主题）；TTS 合成音频（发送要朗读的脚本文本）；**云同步（复用千手设置中心配置；学习记录打包上传到你的 GitHub 私有仓库——注意：国数案例的解析文本也会同步上去，等同外发到 GitHub；音频文件与原件文件不参与同步，超大来源只同步登记信息）**。
- 内部资料全部标注"内部资料·禁外传"；应用不会把你的私有文件发给第三方模型。
- 随时导出 JSON 备份；「删除本应用全部数据」一键清空，不留残余。

## 五、常见问题

| 现象 | 原因与处理 |
|---|---|
| 点"测试合成"报「Unexpected non-whitespace character after JSON」 | 老版本问题**已修复**：接口地址带不带 /v1 现在会自动识别。Ctrl+F5 强刷页面后再点一次即可 |
| 导入某个 docx 报 "reading 'children'" 之类失败 | **已修复**：WPS 导出/超大的 docx 会让第三方解析器崩溃，现在会自动切换内置解析器提取正文（来源表会标注"已用内置解析器完成提取"）。Ctrl+F5 强刷后重新导入该文件即可 |
| 测试合成报「状态码 1004：login fail」 | 路径已通，是密钥不对：去 MiniMax 控制台核对 API Key，注意别带空格/别用错账号 |
| 点"测试合成"报 Failed to fetch | 该 TTS 地址不允许浏览器直连（跨域）。换 MiniMax 官方地址 `https://api.minimaxi.com`；仍不行需用允许跨域的网关，应用不会造假音频糊弄 |
| 测试合成报「接口返回的不是 JSON」 | 地址或路径不对：MiniMax 填 `https://api.minimaxi.com` 或 `https://api.minimax.cn`（带不带 /v1 都会自动识别） |
| 点"生成课程/教案"报 AI 返回格式异常 / content 为空 | 课程已改为分段生成（1~15、16~30 天两次调用），`MiniMax-M3.1-Flash-Preview` 实测可用。若仍报 content 为空，多是 max_tokens 被思考占满，Ctrl+F5 强刷用新版重试；或换非推理型 `MiniMax-Text-01`/`abab6.5s-chat` |
| 课程里某天显示"（系统补全）"或来源标注"待核实" | AI 偶尔会漏掉某天的案例来源/练习/产物，应用已按主题自动检索补全并标"待核实"。锁定前请核对当天内容，可点「改主题」调整 |
| 教案都是"演示模板" | AI 未配置。去统一首页设置中心配好 AI，再重新生成课程 |
| 导入 docx 后检索不到内容 | 老版本问题已修复（表格内容已并入全文）。若仍异常，删除该来源重新导入 |
| 扫描版 PDF 导入后是空的 | 无文字层的图片型 PDF，暂不支持（已知限制） |
| 双击打开后没有"数智学习"卡片 | 用 Ctrl+F5 强制刷新一次 |
| 想换电脑继续学 | 首选：到千手首页「设置中心 → 云同步」启用（GitHub 私有仓库自动合并，手机/电脑自动同步，本栏目自动复用）。未用同步时：导出全部学习数据 JSON → 新设备导入；音频文件用整课 ZIP 带走 |

## 六、已知限制（诚实清单）

1. 真实音频合成、AI 能力树提取已用你的 MiniMax 密钥**实测通过（2026-10-06）**：真实合成 19 秒样张（约 305KB MP3）+ AI 按附件1原文提取 22 个能力项；课程/教案生成共用同一已验证的 AI 通道。样张与能力树校对文件在项目根目录。
2. 扫描版 PDF、图片内容不进解析；PPTX/DOCX 只取文字与表格。
3. 批注在解析文本视图上；源文本大改后旧批注会提示"待重定位"而不是乱搬。
4. 本地双击启动时无离线缓存（浏览器限制），但已下载的 MP3/WAV 是真实文件，随时可听。
5. 本应用是单用户本机工具，没有多用户隔离。
